# Cyber Security Full Course

A structured learning path covering cybersecurity from fundamentals to advanced defensive and ethical hacking concepts.

This repository is designed for beginners and intermediate learners who want clear explanations and practical knowledge.

---

## Course Overview

Cybersecurity is one of the most important skills in today’s digital world. This course covers major domains including networking, system defense, ethical hacking, digital forensics, and more.

---

## Course Contents

### I. Cybersecurity Fundamentals
- Introduction to Cybersecurity
- The CIA Triad (Confidentiality, Integrity, Availability)
- Common Threats, Vulnerabilities, and Risks
- Security Frameworks (ISO, NIST, CIS, etc.)

### II. Networking Essentials
- OSI Model & TCP/IP Concepts
- Ports and Protocols
- Subnetting, Routing, Firewalls, NAT
- Network Monitoring Tools (Wireshark, Nmap)

### III. Cyber Attacks & Defense
- Malware Types
- Social Engineering & Phishing
- DDoS Attacks & Botnets
- Endpoint Protection & Firewall Configuration

### IV. Ethical Hacking & Penetration Testing
- Footprinting & Reconnaissance
- Network Scanning Techniques
- Exploitation and Payloads
- Maintaining Access & Covering Tracks

### V. Security Tools
- Kali Linux Basics
- Metasploit, Burp Suite, Wireshark, Hydra
- Password Cracking Tools
- Security Automation (Python & Bash)

---

## Learning Goals

By the end of this course, you will be able to:

- Understand cybersecurity and networking fundamentals
- Recognize and mitigate common cyber threats
- Use essential security tools responsibly
- Strengthen personal and organizational defenses
- Build a foundation for certifications (Security+, CEH, CISSP)
